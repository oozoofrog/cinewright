# 영화·애니메이션 검토 반영 결과

S04는 양손의 잡기–펼치기–들어 읽기가 서로 다른 포즈가 되었고, S05는 가방부터 문틀 밖으로 드러나는 연속 등장으로 바뀌었다. S02의 선체는 마지막까지 바위·파도와 떨어져 있다. S06은 잎맥, 목재 결, 도기의 드문 교차선, 병의 넓은 명암이 구분된다. 수채의 큰 사각 셀은 농도장 재구성과 96×54 bake로 제거했다. P03은 별도 설계 자산의 어깨 가중치를 수정해 관찰 구간의 검은 쐐기를 없앴다.

수정 대상 **9편 모두 1920×1080, 24fps, 192프레임/8초**로 렌더했다. 기존 카메라와 프레임 번호를 유지했다. 원본 15편의 SHA-256은 최초 검토 manifest와 모두 일치한다. 사용자 작업의 시작 상태와 수정 전 소스는 새 evidence의 `baseline/`에 보존했다. 기존 검토 보고서·영상에 덮어쓰지 않았다.

이 결과는 **오프라인 정지 프레임과 시간 순서의 연속 프레임 관찰**이다. 원속도 영상을 감상한 결과, 인간의 미학적 승인 또는 접근성 인증이 아니다. 기술 검사는 아래와 별개로 통과를 기록한다.

## 수채 방식 비교와 비용

`watercolor/cost-comparison.json`에 입력·비용 원값, `validation/watercolor-equivalence.json`에 동일 사건 검사를 남겼다. Node v26.12.1, Darwin arm64, 같은 실행에서 측정한 소규모 표본이다. draw는 960×540 작업 버퍼의 f24/f72/f144 세 번 평균이며 JIT/캐시 영향을 통제한 성능 인증이 아니다.

| 입력 / 방법 | wet bake / JSON 크기 | overlap bake / JSON 크기 | 재구성 draw wet / overlap |
|---|---:|---:|---:|
| 48×27 + linear | 48.0ms / 5.26MB | 40.6ms / 9.33MB | 20.6 / 16.4ms |
| 48×27 + cubic·종이 입자 | 동일 bake | 동일 bake | 26.8 / 18.6ms |
| 96×54 + linear | 453.4ms / 21.60MB | 443.2ms / 38.54MB | 23.2 / 21.2ms |
| **96×54 + cubic·종이 입자 (최종)** | 동일 고해상도 bake | 동일 고해상도 bake | 21.7 / 24.0ms |

48×27 재구성판은 `P01-48/`, `P02-48/`에 보존했다. 큰 사각은 줄지만 초기 원형 사건의 거친 꽃잎 모양이 남아 최종에는 96×54를 선택했다. `P01-linear/`, `P02-linear/`, `P01-96/`, `P02-96/`에는 대안 기준 프레임이 있다. 픽셀 버퍼는 최종 약 6.43MB, bake JSON은 별도다.

고해상도 입력은 셀 중심 `(x+.5)*2-.5`, 반경×2, diffusion×4, dt÷4, substeps×4, 출력 density 9→36으로 환산했다. **원형 사건의 정규화 위치·반경, 총 물·안료량, seed, 사건 프레임, 프레임당 물리 시간은 같다.** 농도장의 수치 이산화는 다르므로 원본 bake와 bit-identical이라고 주장하지 않는다. solver의 `dt*absorption` 침전 보정 항도 정확한 해상도 불변식은 아니다.

## 실제 관찰 범위와 수락 분리

기술: 관련 회귀 **56개 통과, 실패 0개**. 최종 regression 로그와 모든 render.json의 `seekDeterministic:true`, `errors:[]`, ffprobe의 1920×1080/24fps/192프레임을 확인했다. 모든 수정 영상은 전편을 생성했으며 전후 각각 192장의 native 프레임을 저장했다. 이 사실은 모든 프레임을 개별 원해상도로 보았다는 뜻이 아니다.

시각: 세 미학의 기준 포즈 시트, S04 f156 원해상도 및 f96–131 접촉 확대, S05 f70–105 등장 확대 및 f104/f156/f174 25% 흑백, S01 기준 포즈 및 f44–79 확대, S02 f178 전후, S03 f120 전후/선 off, S04 선 off, S06 f120/f108–119, P03 분리 진단·f24/f64·f48–71 연속 및 ablation을 실제로 열었다. 수채는 두 해상도의 기준 f24/f72/f144, 50% 비교와 초기/중간/후기 연속 시트를 열어 경계·내부를 대조했다. 상세로 저장한 모든 구간은 comparison manifest에 있으며, 원속도 감상으로 표현하지 않는다.

미해결 인간 수락: S01의 방향 선택 의미, S04 읽기 정착의 호흡, S05 최초 시선과 열차 전환, 전체 리듬·정서·피로·접근성. 새 MP4를 원속도로 보여주고 설명문 없는 행동 식별을 받아야 한다. 수채 침전의 독립 물성은 위의 데이터 한계 때문에 추가 연구가 필요하다. P05/P06은 관찰 구도나 동작 목표를 새로 정하지 않았으므로 이번에 solver/rig 결함 판정을 추가하지 않았다.
