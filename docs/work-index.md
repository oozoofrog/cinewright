# 작업 인덱스

작업 ID는 `YYYY-MM-DD-topic`으로 맞춘다. 기존 이름의 날짜를 우선 사용하고, 날짜 없는 자료는 Git 이력이나 본문에서 확인한 날짜만 붙인다. 출처가 없으면 이름을 유지하고 `날짜 미확인`으로 적는다. 아래 11/04 단위는 `3991bed`·`5bd6d89` 이력, 중지·시각 연구는 본문의 11/07·11/08 날짜를 사용했다. 날짜를 추측한 항목은 없다.

보고서는 `docs/<분류>/<작업 ID>/`, 근거는 `evidence/<작업 ID>/`, 일회성 스크립트는 그 아래 `scripts/`에 둔다. 사용자가 실행하는 도구와 그 내부 의존성은 `scripts/`에 둔다. `watercolor-memory.mjs`는 스킬이 안내하는 도구여서 유지했다. 스크립트는 저장소 루트에서 실행한다.

새 미디어와 store·프레임·render-job 폴더, `.agent-loop/`, 큰 텍스트의 지정 경로는 Git에서 제외하되 파일은 보존한다. 기존 추적 파일은 계속 추적한다. 보고서에 직접 삽입한 대표 이미지는 500KB 이하일 때만 `figures/`에서 새로 추적할 수 있다. 이번 보고서에는 해당 이미지 삽입이 없어 새 미디어·figures 추가는 0개다. Frank Mills/Music Box Dancer 관련 미디어는 로컬에만 둔다.

`.direction`과 loop 경로는 **로컬 기록**이다. 기존 경로·run ID는 바꾸지 않았다. 끊어진 과거 링크와 다른 환경의 절대 경로는 기록으로 보존하며, 아래 참조 열과 [상세 목록](../evidence/2026-11-10-artifact-organization/historical-broken-references.json)에 구분했다. `미확인`은 확인 근거가 없다는 뜻이다. 표의 로컬 미디어 크기는 근거 폴더와 명시된 로컬 제작 경로의 합계이며, 서로 상위·하위인 제작 경로가 있으면 행 사이에 중복될 수 있다.

내용 커밋은 각 행에 적었다. 공통 이동은 `41bb19a1ea58`, 추가 release 이동은 `83e0f1d5567c`, 라이선스 이동은 `482ec1d40094`, 경로 참조 보정은 `7302c592f25b`다. 최종 관리 커밋은 자기 해시를 본문에 넣을 수 없어 `git log -1 --format='%H %s'`로 확인한다. 모든 커밋은 `chore/organize-work-artifacts`의 로컬 커밋이며 이번 작업은 push·배포·전역 변경을 하지 않았다. 숨겨진 기존 로컬 제외 자료를 늦게 발견한 커밋 순서 예외와, 초기에 추적된 작은 store 텍스트 22개는 [스테이징 감사](../evidence/2026-11-10-artifact-organization/staging-audits-summary.json)에 명시했다.
