## Findings

1. **P2 — accepted stable watercolor input crashes during drying.** [watercolor.mjs:17](../../../modules/fx2d/watercolor.mjs#L17), validation at line 6, failure at line 20. Run `node evidence/2026-11-08-aesthetic-toolkit-phase02/independent-review/repros.mjs` after the review setup/CPU fixtures, or load [water-drying-repro.json](../../../evidence/2026-11-08-aesthetic-toolkit-phase02/independent-review/water-drying-repro.json) with `createSolver` and advance 60 times. The 9×7, two-pigment input has ordinary initial water amounts 10 and 7. It passes all three stability bounds: diffusion **0.9550884936470538**, water losses **0.9975440462585539**, deposition **0.10401809052564204**, each below 1. Frame 57 succeeds with water in **[9.4e-323, 1.24e-322]**, while mobile pigment is still **[6.38168328688495e-10, 3.0652952991317034e-9]**. Frame **58**, zero based, throws `watercolor: negative pigment: reduce diffusion coefficients`. Expected: accepted coefficients continue with finite, nonnegative, conservative transport throughout the declared 60 frames. Actual: bake aborts before completion. Subnormal flux/divisor quantization defeats the real-arithmetic outflow bound; the documented “tiny flux may underflow and halt movement” limitation does not describe this exception. Minimal correction: make donor outflow fractions positivity-preserving at representable near-zero water, with an explicit dry/subnormal policy, and retain pigment balance. Do not merely remove the exception or clamp away material. Add this drying trajectory to the focused stability tests. [Exact numerical receipt](../../../evidence/2026-11-08-aesthetic-toolkit-phase02/independent-review/repros.json).

2. **P2 — rig-only materialization publishes an asset its runtime rejects, including on update.** [materialize-style.mjs:29](../../../scripts/materialize-style.mjs#L29), conditional factory check at line 40; [auto-rig.mjs](../../../modules/animation/auto-rig.mjs), `validateRig` versus `createRiggedMesh`. Starting from the generated tall rig, change only `inverseBind[0][12] += 1`. `validateRig` returns true; `createRiggedMesh` rejects it with `stored inverse bind disagrees with rest hierarchy`. A valid expressionist object with `rig`, `material`, and **no motion** nevertheless publishes successfully. More seriously, `update:true` replaces a previously valid generated rig asset with this corrupt asset. Expected: reject before new/update publication, preserving the valid package. Actual: successful publication followed by prepare failure. Motion is documented as optional. Minimal correction: perform the rest/inverse-bind factory check for **every rig**, disposing its temporary resources; perform motion compatibility additionally when present. Alternatively make `validateRig` verify inverse bind against hierarchy numerically. Cover both new publication and update preservation. [Reproduction and receipts](../../../evidence/2026-11-08-aesthetic-toolkit-phase02/independent-review/repros.mjs).

3. **P3 — malformed contact windows silently disable correction.** [retarget.mjs:52](../../../modules/animation/retarget.mjs#L52) and line 62. `contact:{windows:{left:[[2,1]],right:[]}}` is accepted; evaluation returns `contacts:[]`. A NaN endpoint is likewise accepted through the JS API. Expected: reject invalid window shape, non-finite seconds, reversed ranges and invalid bounds; valid empty arrays may intentionally disable a side. Actual: an authoring error looks like an intentional no-contact bake. Minimal correction: validate windows once in `createRetargeter`, including endpoints within duration and start ≤ end, with a useful error. Also validate pole/flexion options at construction even when all windows are inactive. This does not invalidate the four valid demo bakes. [CPU adversarial inputs](../../../evidence/2026-11-08-aesthetic-toolkit-phase02/independent-review/cpu.json).

4. **P3 — qualify direct Canvas pixel equality and make the context policy explicit.** [watercolor-physical/index.mjs](../../../modules/styles/watercolor-physical/index.mjs), public `draw`; [watercolor reference](../../../references/styles/watercolor-physical.md). In Electron Chromium **152.0.7977.169**, a fresh default `canvas.getContext('2d')`, `reset`/scale, direct public layer draws and intervening readbacks for `[0,7,37,95,191,191,95,37,7,0,191,0]` reproduce an overlap mismatch. At 540p the repeated frame 7 differs in **79,252 channel bytes**, max **19/255**; frame 0 differs in **29,838 bytes**, max **28/255**. At 1080p the corresponding differences are **301,912 / max 3**, and **106,243 / max 2**. Explicit `{willReadFrequently:true}` and explicit `{willReadFrequently:false}` contexts both pass the same focused repeat check. This is consistent with automatic Canvas backend switching; the cause is an inference, not a measured browser internals trace. The public compositor's tested pixel seeks pass. Minimal correction: document/select a fixed context mode for strict direct-layer readback comparisons and state the supported pixel determinism boundary; add the direct API case to browser validation. Do not promise unrestricted same-browser pixel identity from the compositor result alone. [Measured context comparison](../../../evidence/2026-11-08-aesthetic-toolkit-phase02/independent-review/canvas-context-modes.json), [full overlap measurements](../../../evidence/2026-11-08-aesthetic-toolkit-phase02/independent-review/overlap-browser.json).

## Independent checks actually performed

Commands executed were the review-owned `setup.mjs`, `cpu.mjs`, `repros.mjs`, `extra-cpu.mjs`, `media-audit.mjs`, `closure-audit.mjs`, the public `direction style list`, and targeted inline adverse publication checks. **Watercolor:** inspected the original pairwise transport, sinks, deposition, bake and decoder, compared with the original polygon `wash.mjs`, and read the model/reference and authoring scripts. This is an actual separate solver, not a renamed glaze: conservative equal/opposite grid flux, upwind carried pigment, independent pigment diffusion, water sink ledger, and retained deposited pigment. Units are amount/cell, cell²/s and 1/s, as documented. It models absorption as a sink, without a stored paper-water field; it is not Curtis' full shallow-water/paper/optics model. Seed is metadata only in this version, honestly documented. The bake contains version, complete fixed-step inputs, budget and every pigment frame; random access is a lookup, with no history or hidden live solver. Freeze hashes supply immutable cache identity. Numeric budget is not JSON/heap capacity, also documented.

Ran **80 seeded coefficient trajectories**, 60 frames each, including stability-boundary loss/diffusion, dry pigment, subnormal initial water, deposition and a delayed second brush. **79 completed; one failed as finding 1.** Across successful snapshots, the largest measured water/pigment balance error was **3.161915174132446e-13**, with finite, nonnegative arrays.
