## Coordinate and rig asset v1
Auto rig operates a finite static UV BufferGeometry, upright separated-limb biped T/A rest pose; explicit profile and axes required (default explicit Y-up, X-left, Z-forward, metres). No arbitrary topology promise. autoRig(geometry,{profile:'upright-biped',up:[0,1,0],left:[1,0,0],forward:[0,0,1],landmarks?}) -> JSON-safe {version:1,kind:'cinewright-rig',coordinate:{up,left,forward,unit:'m'},bones:[{name,semantic,parent,position:[local x,y,z],quaternion:[x,y,z,w]}],geometry:{positions,normals,uv,indices,skinIndices,skinWeights},diagnostics,provenance}. Parent integer (-1 root). Standard semantics: hips,spine,chest,neck,head,leftUpperArm,leftLowerArm,leftHand,rightUpperArm,rightLowerArm,rightHand,leftUpperLeg,leftLowerLeg,leftFoot,rightUpperLeg,rightLowerLeg,rightFoot. Rest local position/quaternion, positive unit scale, parent-before-child. Rig JSON contains actual inferred rest values and weight generation, not a fixed rig.
createRiggedMesh(asset,material) -> {mesh:SkinnedMesh,bones:Map semantic->Bone,skeleton,dispose()}; geometry/material ownership documented. Three r180, no DCC required. bind matrices recomputed from asset rest hierarchy; validation compares actual inverse bind/rest skin reproduction. Static input JSON geometry maps to same arrays without skin.
