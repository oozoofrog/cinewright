# 전개와 검토

## 미완성 표현에서 합의까지

요청에 스타일이나 이야기가 있으면 보존한다. 없어도 제작 협의를 시작할 수 있다. 사용자의 기억·감상·취향과 구체적인 반응을 판단 근거로 다룬다. 작법 용어를 아는지 시험하거나 완성된 숏 목록을 요구하지 않는다.

먼저 관객이 이해하거나 느끼기를 바라는 것을 짧게 되짚는다. 원문, 명시한 필수 조건, 제작자가 붙인 해석을 구분한다. 질문은 핵심 의미나 필수 가시적 사실을 바꾸는 항목에 집중한다. 관련 관객·맥락도 기존 자료에 없을 때 확인한다. 길이·비율·원본·권한·스타일·실행 환경은 먼저 조사하고, 사용자의 판단이 필요한 영향만 설명한다.

다음은 제작자가 작성할 짧은 합의 요약이다. 모든 의뢰에 빈 양식을 보내지 않는다.

| 항목 | 남길 내용 |
| --- | --- |
| 원문과 목적 | 사용자의 표현, 확인한 의미. 인용과 해석을 분리한다. |
| 관객·맥락 | 제공받거나 확인한 대상과 쓰임. 모르면 추측을 사실로 쓰지 않는다. |
| 불변 조건 | 반드시 보일 행동·사실·정체성·인과관계, 스타일·길이·비율·원본·권한 |
| 해석과 자유 축 | 선택한 해석, 구도·매체·리듬·생략 중 맡긴 부분, 선택·위임의 메시지 또는 자료 |
| 불확실성과 단서 | 비용·기술·표현상 미확인 항목, 실제 화면에서 확인할 단서. 감정 보장은 하지 않는다. |

의미가 같아 보여도 요구한 행동을 생략하면 다른 작품이 될 수 있다. “손을 들어 상대를 부르려다 망설인다”에서 **손을 올림**, **부르려는 목적**, **망설임**을 나눈다. 손을 올리는 과정이 필수라면 그 움직임을 보존한다. 제시 방식이 열려 있으면 손 일부·시선·그림자·상대 반응 또는 전후 상태로 연결할 수 있다. 바라보기와 이동에도 같은 기준을 쓴다. 명확한 지시는 그대로 수행한다. 수단인지 필수 표현인지 모호한 경우에만 해석을 가설로 밝히고 의미 있는 대체 전에 확인한다.

## 대안과 구현 가능성

색이나 효과만 바꾼 변형 대신, 정보의 순서·시점·생략·시간 관계가 다른 2–3안을 제시한다. 각 안에는 처음 보거나 들을 것, 기대가 달라지는 사건, 끝에 남을 관계, 생략해 추론할 것, 덜 명확해지는 정보를 넣는다. 각 안에서 기대하는 감정·서사 효과는 가설로 밝히며 실제 관객 반응과 구분한다. 첫 경험의 길이는 작품이 정한다. 모든 작품을 첫 5초의 강한 효과로 시작하지 않는다.

권장안은 목적·취향, 단서의 가독성, 전개·연속성과 실행 가능성으로 설명한다. 쉬운 안을 자동으로 고르지 않는다. 도전적인 안을 배제하기 전에 선택에 영향을 주는 불확실성을 범위 안의 짧은 시험으로 확인한다. 사용자에게는 의도·비용·가능성·자료·권한의 차이를 설명한다. 이징 이름이나 제작 설문으로 선택을 대신하지 않는다.

제작 기록에는 후보별로 구현 방식, 필요한 자산, 아래 상태, 추가 작업·불확실성·짧은 검증을 남긴다.

| 상태 | 판단 근거와 다음 행동 |
| --- | --- |
| 현재 공통 기능으로 실행 가능 | 확인한 API·모듈·자산을 명시하고 해당 출력에서 확인한다. |
| 이번 범위의 재사용 모듈이나 작품 코드가 필요 | 작은 변환기 또는 기존 `prepare/draw`로 구현할 범위와 검사를 적는다. |
| 실행 환경 또는 성능 확인이 필요 | 실제 도구 호출·입력 규모를 정해 시험한다. 입력 범위와 속도를 혼동하지 않는다. |
| 현재 기술 스펙이나 승인 범위를 벗어남 | 핵심 의도를 보존하는 실행 가능한 대안을 제시한다. 엔진·의존성·필수 사실 변경은 합의 범위를 확인한다. |

선택 또는 같은 범위의 명시적 위임을 받은 뒤 실제 작품을 만든다. 기존 위임은 그 근거를 남기고 사용한다. 모호한 의뢰나 침묵을 위임으로 기록하지 않는다. 합의한 범위의 타이밍·크롭·레이어 조정은 제작자가 진행한다. 필수 행동·인과관계·기술 범위·위임 범위가 바뀌면 다시 논의한다.

## 짧은 가상 대화

다음은 설명을 위한 **가상 대화**다. 실제 사용자와 합의했다는 기록이 아니다.

> 의뢰자: “집에 돌아와 열쇠를 내려놓는 순간이 좋아요. 하루가 끝났다는 느낌이면 좋겠어요. 지친 걸 과장하지는 않았으면 해요. 손이 열쇠를 탁자에 내려놓고 빠지는 건 보여 주세요.”
>
> 제작자: “열쇠를 내려놓은 뒤 더 서두를 일이 없는 시간을 담으려는 것으로 이해했습니다. 혼자 남는 쓸쓸함보다 쉬기 시작하는 쪽에 가깝나요?”
>
> 의뢰자: “네. 쓸쓸한 쪽은 아니에요. 저는 귀가하면 잠깐 아무것도 안 하는 시간이 좋거든요.”
>
> 제작자: “한 안은 방과 빈 탁자를 먼저 보여 주고, 손이 떠난 자리를 오래 둡니다. 접근 과정은 생략하지만 열쇠를 내리고 놓는 동작은 보입니다. 다른 안은 손과 열쇠를 가까이서 본 뒤 방으로 넓어집니다. 손을 놓는 순간은 더 잘 보이고, 방의 고요함은 나중에 알게 됩니다. 잠깐 아무것도 하지 않는 시간을 중심에 두려면 첫 안을 권합니다.”
>
> 의뢰자: “두 방향 모두 보고 싶어요. 그 차이는 살리고 구도와 길이는 정해 주세요.”

원문에서 내려놓기·손의 퇴장은 필수 행동이다. “쉬기 시작함”은 확인한 의미다. 긴 마지막 hold는 제작자의 해석이다. 마지막 문장은 이 가상 대화 안의 구도·길이 위임이다. 이 문서를 읽은 것만으로 실제 작품 제작 권한이 생기지 않는다. 이번 [작은 예제의 의뢰](../evidence/2026-11-05-production/BRIEF.md)는 예제 제작자가 정하도록 실제 사용자에게 별도로 위임받은 범위다.

## 시퀀스의 판단 사슬

핵심 구간 단위로 다음을 연결한다. 프레임마다 필드를 채울 필요는 없다.

**사용자 원문·확인한 의도 → 관객이 알아차릴 것·이해할 것·느낄 것 → 반드시 보일 행동·사실 → 관찰 가능한 단서 → 보여 주기·생략, 시점, 매체, 배치, 필요한 색·활자·질감, 시간·리듬·소리 → 움직임의 성격·상호작용 → 구현·자산 → 관찰·실패 조건.**

예를 들어 “쉬기 시작함”을 손이 화면 밖으로 빠진 뒤 열쇠만 남는 관계로 옮길 수 있다. 내려놓기가 필수이므로 결과 스틸만 보여 주는 안은 부족하다. 금속 열쇠가 탁자에 닿기 전에 손이 놓이거나, 손을 따라 열쇠가 다시 올라가면 가시적 인과관계가 실패한 것이다. 원화 anchor가 맞아도 이 판단을 대신하지 못한다.

## 스틸, 동작 시험, 전체 초안

구간 목적에 필요한 매체·공간·팔레트·활자·질감을 선택한다. 매체 수나 놀라운 순간의 개수를 할당하지 않는다. 한국어 지침이 모든 작품의 한글 활자를 요구하지도 않는다. 서로 다른 매체는 자체 형식을 유지하되, 필요한 접촉·가림·빛·배경 반응과 값 교환을 실제 출력으로 확인한다.

대표 스틸에서는 형태·실루엣·명암·크기·정보 밀도를 본다. 짧은 동작 시험에서는 프레임 간 이동 간격, 예비 동작, 안착, 겹침·후속 반응 중 필요한 관계를 본다. 무게·재질·힘의 원인에서 속도 분포를 정한다. 모든 대상에 튀는 안착이나 같은 이징을 붙이지 않는다. 기본 카메라 드리프트나 중앙 구도·전환을 이유 없이 반복하는지도 살핀다.

세부 제작 전에 전체 길이의 움직이는 초안을 끝까지 재생한다. 시작·전개·끝, 정보 순서와 기대 변화를 평가한다. 형태·방향·리듬·사건 중 이어서 읽을 단서를 정하되, 모든 구간을 같은 미술로 고정하거나 서로 무관한 작품처럼 바꾸지 않는다. 정지와 침묵은 목적과 단서가 있을 때 유지한다. 움직임 p90, 상시 움직임, 자동 블러를 예술적 목표로 삼지 않는다.

## 실제 출력에서 수정하기

기술 검사와 표현 비평은 같은 실제 출력·revision을 가리킨다. 대표 스틸만으로 움직임을 통과시키지 않는다. 원래 시간과 평가할 크기로 전체를 재생하고, 필요한 핵심 동작만 0.1초 이하 띠나 프레임 단위로 본다. 각 중요한 경계의 `f-1, f, f+1`, 첫·마지막 유효 프레임을 확인한다. `frames`는 span 끝이며 탐색할 프레임이 아니다.

| 구간·시각 | 판정 | 기록 |
| --- | --- | --- |
| 실제 frame 또는 초 | 유지 / 수정 / 재설계 | 관찰한 화면·소리 → 목적과의 차이 → 다음 변경 → 확인 항목 |

회차마다 가장 약한 구간과 원인을 밝힌다. 동작 단서·구도·전개가 약하면 시점·보여 줄 사실·원화 선택·컷 순서·시간 구조를 재설계한다. 이미 목적을 충족한 구간은 변경 횟수를 채우기 위해 바꾸지 않는다. 이전 통과 판단과 새 출력이 충돌하면 새 관찰로 판단을 고친다. 제작 설명으로 보이지 않는 접촉이나 행동을 보충하지 않는다.

구조가 다른 안은 각자의 타이밍으로 처음부터 끝까지 비교한다. 같은 프레임 비교는 같은 조건의 배치·밝기·합성 회귀에 쓴다. 기술 수치는 관계를 판단하는 보조 근거다.

## 독립 검토와 완료

완료 전에 제작 판단에 관여하지 않은 검토자에게 원래 요청, 확정한 해석·제약, 필수 행동·사실, 의도한 정지·hold와 실제 출력을 준다. 가상 의뢰는 누가 정했는지 표시한다. 설득용 제작 해설과 자체 점수를 먼저 주지 않는다. 목적의 가시성, 연속성, 가장 약한 구간과 필수 결함을 검토한다. 허용된 내부 검토 수단을 사용하고 새 사용자 채팅을 만들지 않는다. 수단이 없으면 독립 검토 미검증으로 남긴다.

자동 재생 기록, 제작자 시청·청취 판단, 독립 검토, 실제 관객 반응, 사용자 수락을 각각 기록한다. 검토자의 “유지”는 관객 반응이나 사용자 수락이 아니다. 관객에게는 먼저 작품을 보여 주고 무엇이 보이고 들렸는지 묻는다. 관찰과 해석을 구분하며 제작자의 해석과 같아야 한다고 요구하지 않는다. 사용자의 구체적인 반응과 원한 의미를 기술 용어 사용 여부보다 우선한다.

필수 결함을 수정하고 재검증하면 완료한다. 남은 표현상의 불확실성과 직접 볼 수 없거나 들을 수 없었던 항목을 보고한다. 끝없는 주관적 점수 올리기를 완료 조건으로 삼지 않는다.
