# Silhouette theatre 1.0

Use for storytelling through negative space, articulated cutouts and foreground occlusion. Reiniger's articulated silhouette/multiplane principles inform the grammar; the supplied fox, hare, harbor and curves are original CC0 control data. This is suitable for a small readable gesture, a path opening, or light guiding an object. Photographic segmentation, automatic anatomical recovery and realistic surface shading are unsupported.

Use `modules/styles/silhouette-theatre/index.mjs` exports `validateScene(scene)` and async `prepare(api,{scene|sceneFile})`. Preparation owns its paths, decoded-image references and pixel stage. `evaluate(t)` returns absolute transforms/rigs/diagnostics, `draw(g,t,state)` composites, idempotent `dispose()` releases its stage and references. Existing `manifest v1` compositor invokes disposal, including already-prepared layers when another prepare fails. A failing layer must clean resources it allocated before returning.

The scene declares size/fps/frames/seed, shapes, planes, camera and optional reveal. Coordinates are logical canvas pixels, +y down, hinge rotations radians; all spans are `[from,to)`. Shapes take SVG path or M/L/C/Q/Z command data and explicit evenodd/nonzero fill; opposite winding matters for nonzero holes. Alpha objects take a local project asset and bounds. API limits: 16 planes, 256 objects, 512 paths, 256 bones per rig, canvas max4096. Recommended 3–5 planes, fewer than64 objects; no GPU resources. Decode/network and malformed input errors propagate. Opacity is straight authored alpha; Canvas decodes/composites premultiplied internally; PNG/MP4 differ (final MP4 opaque yuv420p).

`prepareRig2D`/`evaluateRig2D` own hierarchy transforms, clamp hinge angle and reject cycles/missing parent. Each bone pivot is in parent coordinates; shape coordinates are relative to hinge. `poseAt` consumes a corresponding bone-key bank, with explicit linear/hold choice. Puppet pose samples `t.exposed` at object.every; object transform and camera normally consume continuous `t.frame`. `transformClock:'pose'` holds travel as well; `clock:'frame'` bypasses pose quantization. Camera may remain smooth while ears/legs hold. Shapes, rest rig, pose bank and shot are authored assets; no generated anatomy is implied.

`evaluateShot`/`projectPlanes` handle 0..1 depth affine parallax and optional coverage bounds. Give an oversized background or explicit plane bounds; diagnostics flag uncovered viewport. `criticalPairs:[{a,b,minDistance}]` diagnose nearby hinge anchors, not full shape intersection or anatomical validity. Review actual frames for merged ears, faces, crossed legs and hidden hands. `shadow` objects are authored flattened graphics, separate from puppet cutouts and halo objects; they are not physical light shadows. Iris/curtain reveal is a deterministic alpha mask. Edge stipple is anchored to each cutout's paper coordinates and held seed; it is not per-frame screen noise.

Start with three value groups and deliberate holes. Keep the face and forward leg separated from trunks at action beats. A halo has a spatial motivation; avoid filling every silhouette edge. When the [root implementation and inspection conditions](../../SKILL.md#제작과-검토) apply—explicitly required motion/contact/material or investigation of an actually observed original-speed break in 관객 수용—let foreground hide information then reveal a reason to move, use pose holds to make searching and arrival legible, keep safe margins for camera movement, and let the end pose settle rather than drift indefinitely. Otherwise choose these means only as the work needs them; they are not default completion requirements.

`forest`, `harbor`, `portrait` use the same public entry. Recipes are under recipes/styles/silhouette-theatre. Build passes moon/cutouts/provenance through materializeStyle's local assets map. To author a different story, replace shapes/rig/poses/planes/camera, keep the renderer. Root `direction style build silhouette-theatre --scene SPEC --assets MAP --project NEW` accepts the same input. Updates require `--update` and unchanged generated bytes; user edits fail preflight.

A negative example is a head/ear at the same dark value over a trunk; separate by pose, plane gap or a motivated light field, not an automatic glow around every character. The supplied locomotion is a limited authored hinge gait. Judge silhouette tangencies and other form, tonal value, composition, information density and character consistency issues directly in still frames. Judge the temporal effect of foot sliding at original speed; frame comparisons locate form, boundary and compositing regressions. If original-speed viewing is unavailable, hand that unresolved observation over as a 확인 지점 with its location and continue the agreed production scope. Portrait is an alternate shot study, not an automatically reflowed composition. Original-speed human viewing and listening, actual audience responses, and user approval remain separate from automated playback and seek checks. Those checks do not establish 관객 수용.

For match reveal, supply `reveal:{kind:'match',shape:'apertureId',from:0,to:24,center:[x,y]}`; the renderer prepares that authored shape and scales it around the center. Missing shape, invalid reveal/range, invalid path and mismatched pose banks fail scene preflight. Asset provenance deliberately excludes its own file from the hash list, avoiding a circular self hash.
