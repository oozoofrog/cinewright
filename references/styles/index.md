# Aesthetic toolkit

Choose a grammar by what carries the intended expression: negative space/hinges and foreground for [silhouette theatre](silhouette-theatre.md), authored pressure strokes/wash/erasure for [line-wash](line-wash.md), or actual depth/light/shadow/UV surfaces for [expressionist space](expressionist-space.md). Support and exact dependencies come from `node scripts/direction.mjs style list` and catalog/styles.json. Implemented status records the delivered APIs, authored demos and execution evidence; experimental maturity still marks the documented limits. Independent reports and coordinator corrections remain separate receipts. Neither a palette nor a renderer installation establishes an implemented style. For production decisions, follow the [root guidance](../../SKILL.md#제작과-검토): apply motion, contact, material, pose and editing implementation or inspection advice when the brief explicitly requires the relevant motion/contact/material, or when investigating an actually observed break in 관객 수용 during original-speed viewing and listening. Otherwise these are optional authoring means, not a default order or completion requirement. Frame inspection assesses form, boundaries and compositing regressions; it does not establish the experience of time.

Authored scene inputs compile to existing manifest v1. Preserve output frame versus exposed pose/stroke time. Author replaceable assets and record source/license/axes/pivots/alpha/hash, rather than encoding a demo's subject in a reusable renderer. C requires WebGL2; choose an explicit 2D/bake alternative when unavailable. SVG/Canvas and Three r180 are the initial engines. Phase02 adds an explicit [bounded physical watercolor bake](watercolor-physical.md), [section-profile automatic biped rig/skin](auto-rig.md), and [cross-skeleton retarget/contact bake](retarget.md). These experimental opt-in tools keep existing style defaults.

```sh
node scripts/direction.mjs style list
node scripts/direction.mjs style build silhouette-theatre --scene recipes/styles/silhouette-theatre/forest.json --assets /absolute/assets-map.json --project /absolute/unused/project
node scripts/direction.mjs preview /absolute/unused/project --store /absolute/store
node scripts/direction.mjs render /absolute/unused/project --store /absolute/store
```

The assets map uses `{"assets/moon.svg":"/absolute/local/moon.svg"}`. Use each example build helper for its complete asset map. `materializeStyle({project,style,scene,assets,seed,update})` is exported from scripts/materialize-style.mjs. New creation stages and validates bytes before publishing to an unused path. `update:true` stages a complete project copy, then applies generated-file hash checks before directory exchange, restoring the old directory if publish fails. Authored/unknown files survive; modified generated bytes stop the update. This is not a concurrency-safe editing service: stop external writers during generation/update; interruption during directory exchange may leave a `.style-backup-*` next to the project for recovery. Existing writeOwnedFiles itself remains a preflighted multi-file writer, not a transactional filesystem.

Freeze keeps manifest/modules/scene/assets/vendor/license in content-addressed revision. Playback/frame/render use the same revision. All public layer resources are prepared once and released through optional dispose; resources allocated by a failing prepare belong to that prepare. Typed channels remain number/vec2/boolean/string/path; GPU objects and skeletons stay internal. Validate arbitrary/reverse seek images, local frozen imports, alpha/colors at both sizes, actual media frames/PTS, lifecycle, per-effect limits and automatic playback separately from human judgment.

Extension: add a modules/styles/ID entry with validateScene and prepare, a catalog descriptor and local dependency closure, two authored recipes/assets and a focused reference. Export independent effects below the style layer. Keep renderer/browser state out of JSON and do not add mandatory runtime schema fields. Three addon/package requirements belong in a pinned local vendor helper, never a CDN fallback.

For effect defaults, units, count/memory bounds, failure conditions and disposal, read [public effects API](effects.md). `catalog/effects.json` maps these descriptions to actual exports. Standalone effects2d, expressionist effects and the projected-light mixed example are diagnostics and composition examples, not extra aesthetic-pack counts.

Required alpha images are structurally checked and actually decoded in a short-lived local Chromium client before new/update publication. Style builds using alpha assets therefore require the existing `DIRECTION_CHROME`/doctor browser dependency; the decode preflight uses no server, external requests or WebGL context. Invalid images cannot replace the existing generated project. GLB binary/local dependency validation remains separate.
