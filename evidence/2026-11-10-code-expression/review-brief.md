# 독립 검토 입력

먼저 아래 세 영상을 1배속·소리 포함으로 처음부터 끝까지 보고 들은 뒤 관찰을 남긴다. 프레임 시트와 구현 해설은 그 뒤에 읽는다. 이 문서는 제작자 점수나 감정 해석을 제공하지 않는다.

- 대표: `delivery/cups.mp4` — 20초, 960×540, 24fps.
- 변주: `delivery/doorway.mp4` — 10초, 같은 규격.
- 변주: `delivery/fold.mp4` — 12초, 같은 규격.

이번 요청의 고정 조건: 코드로 형태·공간·소리·반복·변화·정지를 저작한다. 현실 모사/인체 자연스러움, 입자/추상/오디오 반응, 규칙→예외→흔적 중 어느 것도 모든 작품의 필수 기본값으로 강제하지 않는다. 기능설명 슬라이드나 단순효과데모가 아닌 짧은 대표 1편과 표현 선택이 다른 변주 2편이다. 공개 자작 자산·음원을 사용한다. 예술 수락과 기술 검증은 분리한다.

확인할 화면 조건: 대표에서는 두 잔이 각기 움직이며 한 잔은 퇴장하고 남은 잔은 앞서 사용된 자리에 도착한다. 문 변주에는 5초 hard cut이 있고, 종이 변주는 두 날개가 다른 시각에 접혔다 열린다. 어느 작품에도 인물은 필수 조건이 아니다.

의도된 정지: 대표 0–2.5 / 5–7 / 10–11 / 13–14 / 16–20초, 문 0–2 / 3.5–5 / 7.5–10초, 종이 0–2 / 6.5–8 / 10–12초. 프레임 정지를 기술 실패로 자동 판정하지 않는다. 음악은 직접 합성한 새 작품이다.

관찰과 해석을 구분해 적는다. 무엇이 먼저/나중에 보이고 들리는지, 기대가 생기거나 꺾이는 곳, 가장 약한 구간, 형태·공간·소리의 단절, 정지와 소리의 끝이 의도대로 유지되는지 확인한다. 직접 볼 수 없거나 들을 수 없었다면 원속도 감상으로 쓰지 않는다.

그다음 대표와 `without-traces.mp4`, `without-first-visit.mp4`를 각각 전체 길이로 비교한다. 사건이나 흔적 제거가 해석과 기다림에 어떤 영향을 주는지는 가설이 아닌 직접 관찰 범위로 기록한다. 정답 서사를 맞힐 필요는 없다.
