# 용어 감사 반영과 리드 판단

[Claude 감사 원문](terminology-audit.md)의 번호를 그대로 사용한다. 감사자는 최종 후보 문서와 사용자 용어 정의만 읽었고 편집에는 참여하지 않았다. 감사 당시 문서는 [audited-documents](audited-documents/)와 [해시](audited-sha256.txt)에 남겼다. 아래 작은 후속 수정은 리드가 직접 처리했다. Claude의 두 번째 감사는 하지 않았으며, 리드가 해당 문장과 정의를 다시 대조했다.

| 지적 | 처리 | 선택과 이유 |
| --- | --- | --- |
| 1 핍진성 부재·대중성 대체·의도/일관성 중복 | 부분 채택 | 창조성·예술성·대중성은 기존 제작 관점이며 핍진성을 대신한 세 축이라고 볼 근거는 없다. 사용자는 대중성을 핍진성으로 바꾸지 말라고 했다. 따라서 기존 관점은 유지했다. 다만 양식화 판단에 핍진성을 실제로 연결하는 것은 유효해 craft-execution:13에 반영했다. 의도·일관성은 핍진성과 동의어가 아니라 판단 근거로 명시했다. |
| 2 확인 지점과 미검증 혼용 | 채택 | craft-execution:27, :59와 direction:78에서 시청·청취 부재 자체는 미검증으로 남기고, 프레임·수치의 관찰이 있을 때만 확인 지점으로 인계하도록 한정했다. |
| 3 acceptance 여러 뜻 | 채택 | 예술 수락을 원속도 시청·청취, 실제 관객 반응, 사용자 수락의 별도 기록으로 풀었다. 영어 문서의 모호한 artistic/aesthetic/human acceptance는 관객 수용·실제 관객 반응·사용자 수락을 구별해 썼다. 완료 요건은 completion requirement, 구현 상태 승인은 coordinator approval of implementation status로 문맥을 명시했다. 접근성 평가는 별도 상태로 보존했다. |
| 4 정의 밖 완료 방해 | 채택 | craft-execution:23에서 서사 설명이 움직임의 표현 판단을 대신하지 못한다는 지침은 보존했다. 다만 밋밋하다는 추정만으로 필수 결함을 선언하지 않으며 원속도 미검증을 구분하도록 바꿨다. music:37의 별도 게이트는 검토 실시 여부를 따로 기록하고 수단 부재 시 미검증으로 인계하는 지침으로 고쳤다. |
| 5 정지화면 판단·예제 Failure | 부분 채택 | 모든 수정 의견이나 예제 실패가 필수 결함이라는 뜻은 아니므로 그 자체를 정의 위반으로 확정하지 않았다. 정지화면 판단을 미루지 말라는 사용자 지시는 유지했다. 루트에서 필수 결함 분류 시 세 범위 중 근거를 명시하도록 보완했고, 예제 실패 징후·표현 수정 의견도 자동으로 필수 결함이 되지 않는다고 명시했다. line-wash의 moving paper grain도 sliding feet와 함께 원속도 영향 미확인 시 확인 지점으로 인계하도록 고쳤다. |
| 6 부드러움·매끄러움 혼용 | 채택 | stillcuts:3과 music-box:19의 보간 관련 표현을 매끄러움으로 맞췄다. 피부·천의 재질을 뜻하는 부드러움은 다른 개념이므로 유지했다. |

경계 사례도 처리했다. 루트 목표 문단의 결함은 아래에서 정의할 필수 결함으로 명시했고 direction:29, craft-execution:17, stillcuts:22의 자동 결함 판정 표현도 필수 결함으로 한정했다. 연속성과 자연스러움은 루트에서 직접 구별했다. 동작의 완성은 동작의 구현과 작품에 필요한 표현을 충족했다는 판단으로 풀어 두 판단의 차이를 드러냈다.

위반이 아닌 참고 4건은 다음과 같이 처리했다. 설득용 해설은 검토자를 설득하려는 해설로 의미가 다르므로 유지했다. 연속 동작·연속 숏·연속 제어값은 정의된 연속성의 대체 명칭이 아니므로 유지했다. continuous human viewing은 해당 문서들에서 original-speed human viewing and listening으로 통일했다. direction의 연속성 정의 위치는 권장안의 전개와 기술 속성을 구별하는 기능이 있어 유지했다.

감사는 정의 위반 여부를 검토한 것이며 작품의 자연스러움이나 관객 수용을 검증하지 않았다. 감사자가 지적한 6건을 모두 확정 오류로 집계하지 않고 위와 같이 리드의 판단과 실제 반영을 구분했다. 이 수정은 행동시험의 계속 제작·필수 행동 보존 지시를 바꾸지 않으며 미검증 분류를 더 정확하게 한다. 행동시험은 감사 직전 문서로 시행했음을 명시하고 추가 반복 시험 없이 그 범위의 증거로 사용한다.

구체적인 전후 문장과 행은 [감사 후 문장별 보완](audit-changes.md)에 있다.
