# 움직임 저작 보완

현재 /Volumes/eyedisk/develop/cinewright 워킹트리가 기준이다. 기존 미커밋 8개 문서와 기존 run·예제·출력·증거를 보존한다. 문서 구현은 shared Sol/Terra 작업자에게 위임하고 Astra가 통합·검증한다. codex는 비활성화되어 사용하지 않는다.

사용자가 초기 질문 생략과 모든 열린 결정을 명시적으로 위임했다. 찻잔 사례는 craft-execution의 미출력 저작 예시로 작성하며 새 렌더를 만들지 않는다. 코드·공용 API·기존 cups·캐시·끊어진 링크를 변경하지 않는다. 커밋·푸시·배포는 하지 않는다. 질문 사용 0.

기존 내용은 위치로 인용하고, 부족한 구절·공간·반복의 차이·과정의 볼 이유를 선택적 산문에 통합한다. 실제 API/작품 저작/미검증을 분리한다. 동등한 짧은 의뢰를 새 독립 작업자 두 명에게 기준선/개편후 문서만으로 제시하여 제작 결정을 대조한다. 이는 계획 증거이며 영상 매력 검증이 아니다.
