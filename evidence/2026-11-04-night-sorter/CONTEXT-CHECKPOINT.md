# 새 컨텍스트에서 이어서 할 작업

같은 채팅의 다음 컨텍스트에서 진행한다. 별도 사용자 채팅, 하위 에이전트, 팀 조정 도구는 사용하지 않는다.

## 입력

1. 패키지 루트 `SKILL.md`.
2. `evidence/2026-11-04-night-sorter/input/BRIEF.md`와 같은 폴더의 원본 `hits.wav`.

이 두 입력만 제작의 출발점으로 쓴다. `SKILL.md`가 안내하는 참조와 CLI를 필요에 따라 읽는다. 새 프로젝트는 `examples/forward-check`에, 재생 파일은 `outputs/night-sorter.mp4`에 둔다. 이 작품의 설계, CLI 명령과 오류, 실제 끝까지 재생한 결과, 화면 캡처 및 근거 범위를 `evidence/FORWARD-RESULT.md`에 남긴다. 독립 관객이나 다른 세션의 평가로 취급하지 않는다.

## 새 작품 제작과 검토 후

`README.md`, `evidence/2026-11-04-initial-production/RESULTS.md`, `evidence/2026-11-04-initial-production/WORKING.md`와 출력 SHA-256에 결과를 연결한다. 그때 이전 구현 근거를 다시 사용한다. 모든 변경은 패키지에 한정한다. 요청의 최초 컨텍스트 ID는 `01a1a50d-d1c8-7bf2-9503-a7f917f4a9e3`이며, 최초 위임을 보낸 채팅 ID는 `01a1a227-cdd8-7ce1-96c8-24aabdfa072f`다. 상위 정본은 `../design/skill-director-review-2026-11-04/IMPLEMENTATION-PROMPT-v2.md`다.
