# 스킬 수정과 근거

검증 의뢰는 STYLE-STORY.md의 스타일과 스토리다. 길이·카메라·형상·빛·음악·검사 방법은 제작자가 선택했다. 기존 구현과 검토를 알고 진행한 같은 컨텍스트의 자체 검증이다. 독립된 블라인드 검증은 미확인이다.

| 확인한 결함 또는 정정 | 스킬의 수정 | 이번 작업의 적용 근거 |
| --- | --- | --- |
| 기존 스킬이 매체 연결과 재생 기록을 요구했지만 묘사 수준·접촉 관계를 판단할 절차가 짧았다 | 대표 화면과 움직이는 구간에서 묘사·공간 관계를 먼저 검토한다 | 첫 모델 프레임에서 지붕 방향·등대 줄무늬 가림·규칙적인 바위·각진 항적을 확인하고 수정했다. 최종 확대 검사에서는 창문 일부가 탑 내부에 들어간 것을 찾아 탑 반지름으로 위치를 다시 계산했다 |
| 전체 초안 11초 컷에서 배의 크기와 위치가 바뀌어 시선이 끊겼다 | 놓친 대상을 지목하고 구도·매체·순서·지속 시간 중 원인에 맞게 바꾼다 | revised-playback에서 배를 따라 출발한 시선이 항구를 지나 부두 가까이 도착하도록 전체 구성을 바꿨다 |
| 이전 보고가 좌표 계승과 원화 질감의 차이를 성과로 평가했으나 사용자는 낮은 품질을 지적했다 | 실제 화면과 기존 판단이 충돌하면 새 관찰로 판단을 수정한다 | 기존 보고는 원본으로 보존하고 이번 보고에서 관객 평가와 기술 검사 범위를 구분한다 |
| 사용자가 검증 입력을 스타일과 스토리로 제한했다 | 검증 의뢰와 제작자가 도출한 계획을 구별한다 | STYLE-STORY.md에는 스타일과 스토리만 있다. PLAN.md의 구현 선택은 제작자의 판단으로 기록한다 |

검사 대상은 지침의 존재만이 아니다. 최종 전체 재생에서 1초 신호, 6–12초 공간 발견, 21초 응답과 마지막 도착을 다시 살핀다. 직접 청취와 사용자 수락은 근거가 생겼을 때 추가한다.

스킬의 화풍·카메라·매체 선택은 열어 두었다. 이번 입체 항구의 미술 선택은 examples/harbor-v2와 제작 기록에 속한다. 전역 스킬 설치는 별도 상태다.
