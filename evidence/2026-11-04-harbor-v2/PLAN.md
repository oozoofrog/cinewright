# 신호의 항구 v2 제작 계획

사용자의 2026-11-04 개선 지시에 따라 새 영상과 미술·연출 검토를 제작한다. 최신 지시는 방향 선택과 제작을 위임했다. 이 디렉터리의 AGENTS.md에 따라 root가 직접 제작과 자체 검토를 수행한다.

소유 경로는 examples/harbor-v2/, evidence/2026-11-04-harbor-v2/, outputs/harbor-v2/다. 최종 검토 뒤 SKILL.md와 references/direction.md에 검증한 판단 방법을 반영한다. 기존 작품 입력과 출력, 이전 검토 문서의 해시를 preserved.json에 기록했다.

## 후보 비교

| 후보 | 시작과 변화 | 종결 | 매체와 미해결 |
| --- | --- | --- | --- |
| 판화가 접히는 해안 | 종이 배의 그림자가 지형의 접힌 면임을 드러낸다 | 종이 표면 전체가 항구가 된다 | 판화·3D 종이, 접힘과 실제 배 형상의 연속성에 높은 제작 비용 |
| 빛이 여는 입체 항구 | 움직이는 배의 작은 불빛, 회전하는 등대 빛이 암초 사이 통로를 드러낸다 | 배가 잔잔한 안쪽 항구로 들어가고 해안 창문이 응답한다 | 무광 모형 3D, 반사·항적·가림·카메라로 관계를 구성한다. 빛이 통로를 읽게 하는지 검증한다 |
| 해도의 지워지는 선 | 빽빽한 지도와 측심선, 배가 지나간 곳의 표식이 지워진다 | 빈 공간의 형태가 해안으로 읽힌다 | 벡터·활자, 기존안의 도판 중심 편향을 유지할 가능성 |

입체 항구를 선택했다. 배와 수면, 등대와 빛이 같은 공간에 있어 기존 결함의 원인을 직접 바꿀 수 있다. 3D 모형의 구조적 세부와 넓은 색면을 함께 쓴다. 고광택 장식, 계기판 텍스트와 데이터 숫자는 미술 목표에 없다.

## 미술과 전개 가설

- 무광 아이보리 도장, 짙은 청록 선체, 산호색 포인트. 검푸른 물에 넓은 저주파 파형과 잔물결을 겹친다. 황색은 조명과 반사에 집중한다.
- 배의 둥근 선체·난간·창문과 등대의 발코니·창문은 같은 축척의 구조로 만든다. 암초는 큰 덩어리와 층별 가장자리로 형상을 단순화한다.
- 0–7초. 가까운 배를 따라간다. 작은 등화와 잔잔한 항적이 위치를 알려 준다.
- 7–11초. 등대 쪽으로 시선을 옮긴다. 빛이 먼저 움직여 암초 사이의 통로를 짚는다.
- 11–24초. 항구 전체를 보며 배가 통로를 지나오는 것을 본다. 항구 안의 불빛이 켜지고 배의 움직임이 멎는다.
- 소리는 24초 새 원본으로 작성한다. 파도와 낮은 지속음 위에 같은 짧은 음형을 되돌린다. 저작·시각 배치는 기록한다. 청취 근거가 생길 때까지 음악 감상 품질은 미확인이다.

## 구현과 검토

- [x] 물·배·등대·암초·항구를 별도 표현 파일로 구현한다. 공통 draw/evaluate 인터페이스를 사용한다.
- [x] 주요 세 시점의 렌더에서 형태·명암·접촉을 확인하고 전체 저해상도 초안을 출력한다.
- [x] 원래 속도로 전체 MP4를 재생하고 약한 구간을 수정한다.
- [x] 동일 개정본의 미리보기와 최종 출력에서 단서를 대조한다.
- [x] 임의 탐색 재현, 오디오 결합, 초·후반 동기, 원본 보존을 검사한다.
- [x] 실제 수정 사례에 근거해 스킬을 보완하고 재적용한다.
- [x] 두 영상의 재생 진입점과 자체 평가·미확인 범위를 전달한다.

재생 로그와 프레임 캡처는 관찰 근거다. 관객 반응이나 직접 청취로 기록하지 않는다. 일반 엔진의 기존 통과 근거는 유지하며 새 작품에 영향을 받는 검사를 추가한다.

## 검증 입력에 관한 사용자 정정

사용자는 검증 의뢰에 스타일과 스토리만 제공하도록 지시했다. STYLE-STORY.md를 검증 입력으로 삼는다. 이 계획의 구현 방법·시간 배분·카메라·검사 항목은 제작자가 도출한 결정이며 검증 의뢰의 요구 조건이 아니다. 이후 스킬의 입력 안내와 검증 보고에서도 이 구분을 유지한다.

전체 초안의 11초 컷에서 배가 갑자기 작아지고 마지막 부두 도착도 작은 화면에 머문다. 처음의 배를 따라가던 시선이 항구 전체를 발견하고 마지막에 부두 가까이 다가가는 구성으로 다시 제작한다. 등대를 별도로 보는 구간의 정보는 카메라 이동 중 나타나는 공간 관계로 전달한다. 이 변경은 스타일과 스토리를 읽은 제작자의 선택이다.
