# 코드 표현 개편 독립 검토

2026-11-10. 검토 대상: `/Volumes/eyedisk/develop/cinewright`. 제작·문서 개편에 참여하지 않은 검토 세션에서 작성했다. 하위 에이전트와 팀 조정 도구를 사용하지 않았다. 쓰기는 이 보고서와 `independent-review-evidence/`에만 했다.

**확정적 결함에 따른 필수 수정: 없음.** 작법의 관계·시간·형태·소리 중심 전환이 실제 코드와 서로 다른 세 출력 선택으로 이어진 것은 확인했다. 그러나 **완성작 대표 1편과 변주 2편의 표현적 성취까지 수락한 검토는 아니다.** 특히 `fold`는 관찰한 화면에서 접기 동작 연구의 성격이 강하다. 기술적으로 작동한다는 이유로 세 편 모두 완성작이라고 판정할 근거는 부족하다.

## 확인 범위와 관찰 순서

`review-brief.md`를 먼저 읽고, delivery 세 MP4와 제거 비교본 두 MP4를 직접 디코딩했다. 제작자 해설보다 먼저 [출력 관찰 기록](independent-review-evidence/output-observations-before-docs.md)을 저장했다. 그 뒤 루트 `SKILL.md`, 플러그인 wrapper `skills/cinewright/SKILL.md`, `references/craft-execution.md`, `craft.md`, direction/format의 관련 절, 공개 예제 소스·README·라이선스, 구현 기록·인수인계·작법 개편 기록과 기술 증거를 읽었다.

**직접 수행한 것은 시간순 정지 프레임 관찰과 코드·신호 검사다. 원속도 시청·직접 청취는 수행하지 못했다.** 이 세션의 확인 가능한 입력 경로로는 재생되는 영상과 소리를 직접 감각적으로 검토할 수 없었다. 음소거 자동재생·오디오 데이터 디코딩을 청취로 간주하지 않았다. 브리프가 요구한 소리 포함 전체 1배속 감상과 전체 길이 실시간 제거 비교는 미수행이다.

- 영상 전체를 디코딩했지만, 눈으로 확인한 것은 모든 파일의 **0.5초 간격 프레임과 마지막 유효 프레임**이다. 실제 MP4에서 추출했고 제작자가 만든 시트는 첫 관찰에 사용하지 않았다. 480×270으로 축소한 시트라 원본 크기의 미세한 결함까지 확인한 것은 아니다.
- 추가 연속 프레임: cups f58–65(2.417–2.708초), f261–272(10.875–11.333초), f375–386(15.625–16.083초); doorway f114–125(4.750–5.208초); fold f108–119(4.500–4.958초), f192–203(8.000–8.458초). cups 연속 시트는 최초 관찰 저장 후에 추가 열람했다.
- [추출 스크립트](independent-review-evidence/extract.py), [입력 SHA-256·ffprobe·프레임 수](independent-review-evidence/manifest.json), `*-overview-*.jpg`와 `*-consecutive-*.jpg`를 보존했다. “전체 프레임 디코딩”은 “전체 프레임 직접 관찰” 또는 “전체 원속도 감상”을 뜻하지 않는다.
- 기술 검사는 기존 유효 증거를 재사용했다. 전체 렌더·브라우저 검증·회귀 테스트를 재실행하거나 새 테스트를 추가하지 않았다.

## 해설 전 출력 관찰과 표현 판단

**대표 — cups, 0–20초.** 두 잔이 떨어져 있고, 2.5–5초 청록 잔이 먼저 접근하며, 7–10초 흰 잔이 뒤따라 간격을 좁힌다. 11–13초 청록 잔은 왼쪽 화면 밖으로 나간다. 14–16초 흰 잔은 청록 잔이 중간에 머물렀던 자리로 옮겨 간다. 16초부터 끝까지 그 배치와 왼쪽의 고리형 자국이 남는다. 접근·응답·퇴장·자리 이전의 순서는 프레임만으로도 구별된다. 두 대상의 관계가 전후로 달라지므로 이동 API 하나를 보여 주는 시연만으로 보지는 않는다. 특정 이별 이야기나 슬픔이 전달됐다는 판단은 하지 않는다.

잔의 작은 크기, 고정 구도와 대각선 공간에 비해 사건의 변화량은 절제되어 있다. 가장 판단을 유보하는 구간은 16–20초다. 남은 자리라는 화면 정보는 있지만, 이 배치가 음악의 끝과 함께 4초를 유지할 힘이 있는지는 원속도·청취 없이 평가할 수 없다. 더 빨리 자르거나 상시 움직임을 더하라는 수정 요구는 하지 않는다.

**변주 — doorway, 0–10초.** 어두운 공간 오른쪽 문이 열리며 밝은 면과 바닥 빛이 넓어진다. f119→120, 정확히 5초에 밝은 공간 왼쪽의 어두운 문으로 바로 바뀐다. 관찰한 경계 프레임에는 삽입된 검정 화면이나 중간 블렌드가 없다. 이 컷은 좌우·명암·화면의 비중을 재배치한다. 후반 오른쪽 사각 면의 밝기가 줄고 빈 윤곽이 남는다. 소스를 읽기 전에는 이것을 빈 액자 또는 벽의 면으로 읽었고, 반드시 문 반대편이라고 단정하지는 못했다.

문 열기 시연을 넘어서는 선택은 컷과 공간 대비에 있다. 다만 6.5–10초의 약한 밝기 변화와 정지는 첫 절반보다 적은 정보를 준다. 두 공간이 하나의 문 양쪽으로 연결되는지, 소리의 선행·후행이 그 연결을 돕는지는 사람 감상이 필요하다. 의도한 hard cut과 hold 자체를 단절 결함으로 분류하지 않는다.

**변주 — fold, 0–12초.** 세 색면 중 왼쪽이 먼저 접혀 노란 뒷면을 드러내고 오른쪽이 뒤따라 겹친다. 6.5–8초 닫힌 상태, 8–10초 순차 개방, 10–12초 양 끝이 조금 꺾인 열린 상태가 보인다. 시작은 평평하고 끝은 약간 접혀 있으므로 완전히 같은 상태의 복귀는 아니다. 접힌 상태의 짧고 긴 가로선도 보인다. 닫힌 구간의 그림자 폭은 종이의 좁아진 폭과 대응하며 이전 보고서의 펼친 폭 그림자 문제는 현재 관찰에서 재현되지 않았다.

세 편 중 **동작·형태 시연에 가장 가까운 결과는 fold**다. 시간순 화면에서 읽힌 정보 대부분이 두 날개의 접힘과 펼침 한 주기에 모인다. 앞뒷면·가림·시차를 저작한 사실은 분명하지만, 그 자체가 완성작의 성취를 보증하지는 않는다. 해설의 “응답”이 소리와 간격에서 실제로 경험되는지는 확인하지 못했다. 이것은 관찰에 근거한 표현상 유보이며 확정된 버그나 전면 재작업 요구가 아니다. 서사를 추가하거나 현실적인 종이 물성을 구현해야 한다는 뜻도 아니다.

세 편 모두 관찰한 출력에는 기능 이름·수치·설명 슬라이드가 없다. 그렇다고 설명이 없다는 사실만으로 작품성을 수락하지 않는다. cups의 관계 변화, doorway의 공간 역전, fold의 면과 시차는 서로 다른 제작 선택이다. 색만 바꾼 세 복제본은 아니다. 한편 평면 벡터, 제한된 색, 고정 구도, 드문 사건과 긴 정지를 공유하므로 넓은 표현 스펙트럼을 증명하는 묶음도 아니다. 요청은 서로 다른 선택이지 기법 다양성 할당량이 아니므로 이를 필수 미달로 분류하지 않았다.

## 제거 비교에서 직접 확인한 차이

`without-traces.mp4`는 접근과 퇴장·자리 이전이 남아 있으나 바닥 고리가 없다. 마지막 화면은 흰 잔 하나와 빈 면이다. 과거 위치를 현재 화면에 남기는 정보가 줄어든 것은 직접 관찰했다. 그 때문에 관객의 기다림이나 여운이 약해졌다는 감상 결과는 얻지 못했다.

`without-first-visit.mp4`는 청록 잔이 처음부터 가운데에 있어 2.5–5초 첫 접근과 최초 왼쪽 고리가 없다. 후반 퇴장과 흰 잔의 이동은 남고, 흰 잔이 가운데 고리를 가리면 마지막 왼쪽에는 빈 면만 남는다. 초기 사건과 위치 이력이 함께 바뀌는 비교이므로 감정 효과를 단일 변수의 인과로 확정하지 않는다. 두 비교본의 전체 시간 범위를 0.5초 표본으로 살폈지만, 각각 전체 1배속으로 비교 감상한 것은 아니다.

## 문서가 실제 제작으로 이어졌는가

[작법 실행](../../references/craft-execution.md)의 시작 질문과 선택 경로는 관계·시간·소리에서 출발한다. 포즈·접촉·물성 도구는 필요한 경우의 경로로 남아 있다. 현실 모사, 추상 이펙트, 규칙→예외→흔적을 공통 필수 공식으로 삼지 않으며, 정지·침묵·hard cut을 허용한다. `direction.md`와 `craft.md`도 이를 유지한다. 플러그인 wrapper는 루트 SKILL로 연결된다.

실행 대응도 있다.

- `examples/relation-studies/studies.mjs:7`의 두 독립 위치 트랙은 MP4의 먼저/나중 이동에 대응한다. `cups.mjs`는 현재 frame까지의 `placements`를 평가한다. table→vessels 값 교환은 현재 좌표 전달이며 누적 기억 자체라고 포장하지 않는다.
- `doorway.mjs`의 f120 분기와 f156–180 빛 소거가 컷·후반 밝기 변화에 대응한다. 누적 자국·입자·음량 반응을 넣지 않아 대표의 공식을 반복하지 않는다.
- `studies.mjs:22`의 좌우 다른 키 시각과 `fold.mjs:13`의 힌지·꼭짓점 대응이 순차 접힘을 만든다. 자동 의미 보간이나 물리 시뮬레이션으로 설명하지 않는다.
- `studies.mjs`의 score는 화면과 독립된 시각에 음을 배치한다. 코드상 cups 마지막 음은 16초, doorway 음은 4.5초 및 5.333초에 컷 앞뒤, fold 첫 음은 1.75초로 접힘보다 먼저 시작한다. `score.mjs`가 합성해 실제 MP4 오디오로 연결된 것은 신호 비교로 확인했다. **그 소리가 어떤 질감·호흡으로 들렸는지는 미확인이다.**

따라서 문구만 개편하고 예제는 기존 기능 시연 그대로 둔 상태는 아니다. 다만 실제 원속도 관찰→표현 수정→재감상이라는 작법 전체를 수행했다고 할 증거는 없다. 구현 기록도 직접 감상을 하지 않았다고 명시한다. 현재 근거는 저작 선택, 프레임 기반 수정, 기술 검증에 이르며, 경험으로서의 완성도 검증은 남아 있다. 문서 담당이 갱신 중인 상태 문구나 구현 기록의 과거 “통합 중” 언급을 영상 결함으로 세지 않았다.

## 기술 증거 재사용과 표본 확인

기존 `delivery/verification/report.json`에는 480/240/288프레임의 정·역·직접 seek 일치, 별도 frame job, 구간 render, PCM/AAC 비교와 자동재생이 기록되어 있다. `verify.mjs`의 실제 검사 내용도 읽었다. `regression.log`의 179개 통과와 `example-tests-delivery-tail.log`의 신규 2개 통과를 기존 증거로 재사용했다. 자동재생은 음소거 상태이고 제시 프레임 수가 전체보다 적으므로 원속도 지각 품질이나 무누락 표시를 검증한 것으로 확대하지 않는다.

독립 표본 검사는 [스크립트](independent-review-evidence/spotcheck.py)와 [결과](independent-review-evidence/technical-spotcheck.json)에 남겼다.

- 세 delivery 파일의 SHA-256이 `results.json`, 각 canonical `work.mp4`, `job.json`의 해시와 일치했다. job/revision도 기존 검증 보고서와 일치했다.
- 예제 파일 10개의 현재 해시가 기존 `source-hashes.json`과 모두 일치했다. 원본 예제 코드 변경으로 검증이 무효화된 정황은 없었다. 전체 회귀 관련 모든 파일의 이력을 별도 감사한 것은 아니다.
- 실제 MP4 디코딩은 오류 없이 끝났으며 H.264/AAC, 960×540, 24fps, 정확히 20/10/12초와 480/240/288프레임을 확인했다.
- 세 MP4의 AAC를 다시 디코딩해 delivery 프로젝트의 PCM과 비교한 상관·RMS 오차가 기존 보고서와 일치했다. 끝에 각각 약 1.167/1.552/0.331초의 정확한 디지털 무음이 남았다. 측정 샘플 피크는 모두 full scale 미만이었다. 이는 끝에서 유효 신호를 강제로 자른 정황이 없다는 제한적 근거이며, 클릭 부재·적절한 음량·좋은 여운을 청취로 확인했다는 뜻은 아니다. AAC의 미세한 시작/끝 잔류는 PCM의 음표 시각과 구분했다.

자작 Canvas 코드와 직접 합성 경로, 예제의 재사용 허용 문서를 확인했다. 외부 원곡·샘플을 불러오는 경로는 해당 예제에서 보이지 않았다. 법적 권리 보증이나 외부 출처 전수 감사는 하지 않았다.

## 필수 수정, 요청 미달, 한계의 구분

**필수 수정: 없음.** 이번 확인 범위에서 파일·시각·근거를 갖춰 확정할 수 있는 수정 대상 결함을 찾지 못했다. 그러므로 코드 변경, 추가 효과, 새 장면이나 전면 재제작을 요구하지 않는다. 미관찰 영역이 통과했다는 뜻은 아니다.

**요청 충족을 확인한 부분:** 관계 중심 작법 개편, 실행 가능한 대표+변주 두 편의 납품, 세 편의 다른 표현 선택, 브리프의 가시적 행동, 의도한 정지, 실제 오디오 트랙, 기술 증거의 납품본 연결.

**미완료·유보:** 소리 포함 전체 원속도 독립 감상은 수행하지 못했다. 특히 fold가 기하 동작 시연을 넘어서는지와 세 편의 독립 완성작 성취는 미확인이다. “단순 기능데모를 완성작으로 포장하지 말라”는 조건에 대해 무조건 합격으로 보고할 수 없다. 현재 정확한 인계 표현은 관계를 저작한 세 편과 기술 검증이 준비됐으며, 작품으로서의 최종 판단은 남아 있다는 것이다.

**명시적 범위 제한:** 이번 저장소 개편은 원격/활성 플러그인에 배포되지 않은 상태다. 인수인계에도 미배포가 명시되어 있다. 이 검토에서는 설치·원격 상태를 변경하거나 새 세션의 스킬 로딩을 검증하지 않았다. 미배포는 영상 결함과 구분하며 전역 반영 완료로 보고해서는 안 된다.

사람이 제작 해설 없이 소리를 켜고 처음부터 끝까지 볼 때 확인할 항목은 다음과 같다. 이는 새 창작 요구가 아니라 남은 감상 검증이다.

- cups 전체와 제거 비교본 두 편: 7–11초의 서로 다른 응답이 읽히는지, 11–16초 자리 이전이 보이는지, 16–20초 정지와 소리의 끝이 어떤 경험으로 남는지.
- doorway 전체: 4.5–5.4초 음과 컷의 관계, 같은 공간 양쪽이라는 연결 여부, 6.5–10초 빛 소거·정지가 필요한 길이로 느껴지는지.
- fold 전체: 2–6.5초와 8–10초의 시간차가 단순 순차 동작 이상의 관계로 경험되는지, 닫힌 hold와 마지막 부분 개방·소리가 한 편의 끝으로 작동하는지.

이 보고서는 제한된 독립 프레임·코드 검토다. 실제 관객 반응, 사용자 수락, 프로페셔널 최종 수락은 얻지 않았다.
