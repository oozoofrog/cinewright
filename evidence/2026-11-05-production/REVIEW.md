# 「하루를 내려놓는 자리」 출력 검토

수정본 A와 B의 접촉 결함은 독립 재검토에서 **ADDRESSED**로 판정됐다. 확인한 프레임에 남은 필수 수정은 없었다. A의 넓은 구도에서 접촉을 1배속 첫 시청 중 알아보는지는 미확인이다. 이 문서는 기존 제작자 관찰과 개정본별 독립 검토를 종합한다. 요약 작성자가 새로 영상을 연속 시청했다는 기록은 아니다.

| 현재 출력 | 개정본 | 전체 영상 |
| --- | --- | --- |
| A · 빈 자리의 시간 | `f1d51eaa10567cba25eb1787fa5e65d8776f4da185c1c2bd4e290a0a658abc04` | [192프레임·8초 MP4](../../.direction/production/jobs/b030aad5-33a8-4a71-9977-994c046e3b50/work.mp4) |
| B · 손에서 방으로 | `4355e5ec4829e994785e96c7788387d0a61f44dd43d2aa566cb3124cdd86fac0` | [168프레임·7초 MP4](../../.direction/production/jobs/c5d57e2c-0459-4def-a8c2-b8f49ea5748c/work.mp4) |

두 안은 640×360, 24fps이며 의도된 무음이다. 모든 프레임 번호는 0부터 시작한다. 표의 시간은 프레임 시작 시각이다. 마지막 프레임 뒤 종료 시각은 A 8초, B 7초다.

이 문서의 영상과 관찰은 **scene의 own key 보강 전 고정 개정본**을 대상으로 한다. 현재 scene은 `__proto__` 이름을 보존하도록 원화 사전만 수정했으며 새 freeze는 다른 revision이 된다. A/B의 일반 이름·작화·타이밍과 보존 영상은 그대로다. 현재 소스의 364/364 회귀와 이전 영상 검증 당시 360/360은 [RESULT](RESULT.md#기술-검증과-관찰-범위)에 구분했다. 이번 소스 보강으로 새 영상이나 새 표현 검토를 주장하지 않는다.

## 판단 기준과 관찰 출처

[가상 의뢰](BRIEF.md)의 목적은 열쇠를 놓은 뒤 더 서두르지 않아도 되는 시간을 남기는 것이다. 내려오기, 탁자 접촉, 손가락 열기, 손의 퇴장은 필수 행동이다. 손과 열쇠가 함께 사라지거나 떠 있는 상태에서 놓는 장면은 허용하지 않는다. 정지한 원화, 단계 노출, 고정 카메라, 긴 hold와 무음은 의도한 선택이다.

리더는 원문·확정한 조건·의도된 정지를 [독립 검토 의뢰](output-review-brief.md)로 전달했다. 독립 검토자는 제작자의 권장안이나 자체 점수를 근거로 삼지 않고 실제 경계 띠·동작 띠·640×360 디코드 PNG를 확인했다. 제작자가 선택한 가상 취향은 실제 사용자의 취향이나 수락이 아니다.

## 정지 이미지, 동작 띠와 재생의 구분

독립 재검토자는 수정본의 [A 경계 띠](../../.direction/production/task-4-runs/contact-fix-1/inspection/a/boundary-decoded.png), [A 동작 띠 f34–104](../../.direction/production/task-4-runs/contact-fix-1/inspection/a/dense-decoded.png), [B 경계 띠](../../.direction/production/task-4-runs/contact-fix-1/inspection/b/boundary-decoded.png), [B 동작 띠 f16–92](../../.direction/production/task-4-runs/contact-fix-1/inspection/b/dense-decoded.png)를 직접 봤다. 접촉·퇴장·전환의 조밀한 프레임과 실제 크기 PNG를 함께 확인했다. 대표 스틸 몇 장만으로 전체 동작을 통과시킨 기록이 아니다.

작화 수정은 한 SVG와 두 복사본에 한정됐다. 구조·타이밍은 바꾸지 않았다. 이전·이후의 같은 시각 비교는 접점과 형태의 회귀를 확인하는 데 썼다. A와 B의 표현 차이는 각각의 8초·7초 시간 구성으로 비교해야 한다.

[수정본 기술 기록](task-4/runs/contact-fix-1/inspection/receipt.json)에는 각 안의 원래 시간에 따른 자동 live 재생과 MP4 1배속 재생이 있다. 둘 다 끝까지 도달했다. MP4 재생에서 브라우저가 보고한 드롭은 A 1프레임, B 0프레임이다. 이 값은 숨기거나 더 좋은 재생으로 대체하지 않았다. 48kHz 스테레오 디코드 PCM의 peak 0은 의도된 무음과 맞는다.

제작자의 정지 프레임 관찰, 리더의 별도 PNG 확인, 독립 검토자의 유지·수정 판정과 자동 재생 기록은 서로 다른 근거다. 독립 검토자는 영상 스트림을 중단 없이 연속 시청하거나 직접 청취하지 않았다. 직접 연속 시청·청취, 실제 관객 반응과 실제 사용자 수락은 미확인이다.
