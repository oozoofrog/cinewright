# Cinewright 예제 A·B 독립 출력 검토

A와 B 모두 손이 열쇠를 내리고, 손가락을 편 뒤, 열쇠를 남겨 둔 채 프레임 밖으로 나가는 순서가 보인다. **두 안의 필수 수정은 손가락을 펴기 전에 열쇠가 상판에 닿았다는 단서를 분명히 하는 것이다.** B의 근접 구도에서 열쇠와 그림자 사이의 띠가 선명하다. A의 넓은 구도에서는 탁자 경계가 가까워 열쇠가 놓였다고 읽힐 여지가 있지만, 열쇠 하단에 닿는 지점은 구별하기 어렵다. 두 구도와 동작 순서는 유지하고 접점 표현을 수정한다.

두 안의 추출 프레임에서 손·열쇠·탁자의 형태가 이어진다. 열쇠가 튕기거나 번쩍이는 모습, 과장된 손 떨림, 설명 자막은 관찰한 범위에서 보이지 않는다. A의 첫 진입과 정지 길이, B의 컷 리듬은 표현상의 선택이다. 재설계가 필요한 구간은 확인하지 않았다.

다음 확인은 각 안을 640×360에서 1배속으로 본 뒤, A f54–80과 B f42–68에서 열쇠의 접점이 손가락을 펴는 프레임보다 앞서 보이는지 확인하는 것이다. 손이 빠진 뒤와 B의 컷 직후에도 같은 상판 위치에서 접점이 유지되는지 확인한다.

## 검토 증거와 범위

- 검토 기준은 [독립 출력 검토 의뢰](output-review-brief.md)다. A는 `b80a591239cabcf6a440cf9a3bf788a74b7f7094f4eca89e0b2d9f267930fb79`, B는 `f48dddf994816b294cbf1ec79764643241f3342afbb48b99afd219b52569ccd5`다. [A MP4](../../.direction/production/jobs/da55c2d8-ee74-4b4c-adc7-3f0cb9170044/work.mp4) · [B MP4](../../.direction/production/jobs/7d4505f5-ee13-49f9-baa3-95ed9924172a/work.mp4)
- 경계 프레임 띠, A f34–104와 B f16–92의 연속 프레임을 배열한 띠, 각 표에 링크한 640×360 PNG를 직접 봤다. 프레임 번호는 0부터 시작한다. 시간은 프레임 시작 시각을 소수 둘째 자리까지 표시했다. PNG 파일명은 추출 순번이므로 시간축 프레임과의 대응표를 사용했다. [A 경계](../../.direction/production/task-4/a/boundary-decoded.png) · [A 동작 구간](../../.direction/production/task-4/a/dense-decoded.png) · [A 대응표](../../.direction/production/task-4/a/decode-comparison.json) · [B 경계](../../.direction/production/task-4/b/boundary-decoded.png) · [B 동작 구간](../../.direction/production/task-4/b/dense-decoded.png) · [B 대응표](../../.direction/production/task-4/b/decode-comparison.json)
- 기술 기록상 두 MP4 모두 640×360, 24fps다. A는 192프레임, B는 168프레임이다. 640×360에서 1배속 자동 재생은 끝까지 도달했고, 브라우저가 보고한 드롭은 A 1프레임, B 0프레임이다. 두 안의 무음은 의도된 조건이며 디코드한 PCM 피크는 0으로 기록됐다. [기술 기록](task-4/receipt.json) · [A 자동 재생 기록](../../.direction/production/task-4/a/mp4-playback.json) · [B 자동 재생 기록](../../.direction/production/task-4/b/mp4-playback.json)
- 검토자는 MP4의 영상 스트림을 처음부터 끝까지 연속 시청하거나 오디오를 직접 청취하지 않았다. 동작 사이의 순서와 화면 단서를 판정했고, 1배속에서 느끼는 멈춤·전환·움직임의 리듬은 미확인이다. 이 판정은 가상 의뢰에 대한 독립 검토이며 실제 관객 반응과 사용자 수락은 별도다.
