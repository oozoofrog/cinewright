# Simulated response — explicit action

This is a fictional skill probe. It records no actual user agreement, delegation, or production.

## 사용자에게 보낼 가상 응답

두 안 모두 손이 올라가기 전부터 중간 높이에서 멈춰 있는 순간까지 직접 보여 줍니다. 상대를 부르려는 의도가 먼저 읽히고, 손이 멈출 때 그 의도가 망설임으로 바뀌는 장면으로 이해했습니다.

**1안 · 같은 화면에서 지켜보기**

인물의 상반신과 낮게 놓인 손을 한 화면에 둡니다. 인물이 화면 밖의 상대를 바라보면 손이 시선을 따라 올라갑니다. 곧 부를 것처럼 보이다가 손이 중간 높이에서 멈춥니다. 시선은 상대 쪽에 남고 주변 소리만 이어집니다. 한 컷에서 시선과 손을 함께 읽을 수 있습니다. 두 사람 사이의 거리와 상대의 표정은 화면 밖에 둡니다.

**2안 · 두 사람을 먼저 보고 손에 가까이 가기**

첫 컷에서 두 사람의 위치를 보여 줍니다. 손이 움직이기 직전에 손과 팔꿈치가 함께 보이는 가까운 화면으로 옮깁니다. 그 화면 안에서 손이 올라가다가 중간에 멈추고, 짧은 정적 속에 그대로 머뭅니다. 상대가 어디에 있는지 먼저 알 수 있고, 멈춘 높이와 자세도 더 잘 보입니다. 손이 멈출 때 인물의 표정과 상대의 반응은 화면 밖에 둡니다.

1안을 권합니다. 시선에서 손의 움직임으로 이어지는 흐름을 한 컷에서 볼 수 있어, 언제 손을 들기 시작했고 어디서 멈췄는지 따라가기 쉽습니다. 두 사람 사이의 거리가 장면에서 중요하다면 2안이 더 잘 보여 줍니다. 어느 쪽이 원하신 장면에 더 가깝나요?
