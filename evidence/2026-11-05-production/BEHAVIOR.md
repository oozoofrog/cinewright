# 제작 대화 지침의 제한된 행동 검증

갱신한 `SKILL.md`와 `references/direction.md`를 읽은 새 문맥에서 가상 사례 다섯 건을 각각 한 번 확인했다. 호출에는 검토자 기본값인 `gpt-6.1-sol`과 `high`를 요청했다. 이 기록은 요청한 호출 설정이며 제공자의 런타임 식별을 별도로 입증하지 않는다.

검사 지시에는 실제 제작·사용자 질문 도구·다른 파일 수정을 금지하는 조건이 포함됐다. 따라서 아래 결과는 **문서와 이 검사 조건을 함께 적용한 응답 관찰**이다. 스킬만으로 같은 행동이 항상 나온다는 증거가 아니다. 응답은 실제 사용자 합의나 제작 결과가 아니다.

| 사례 | 응답에서 확인한 내용 | 근거 |
| --- | --- | --- |
| 방향을 아직 고르지 않은 의뢰 | 우산을 기울이고 어깨가 젖는 사실을 보존했다. 두 시점의 대안과 권장안을 제시한 뒤 선택을 요청했다. 실제 제작을 시작하지 않았다. | [응답](behavior-unselected.md) |
| 같은 범위의 기존 위임 | 확정한 1안·8초·가로 화면·연필선을 다시 승인받지 않았다. 대표 화면과 손이 올라가 멈추는 동작 시험을 다음 행동으로 정했다. | [응답](behavior-delegated.md) |
| 명시적으로 보여야 할 행동 | 두 안 모두 손의 상승과 중간 정지를 직접 보이는 구도로 설명했다. 그림자나 상대 반응만으로 대체하지 않았다. | [응답](behavior-explicit-action.md) |
| 모호한 표현 수단 | 카메라 회전을 답답함을 표현하려고 떠올린 수단으로 해석했다. 회전안과 고정 화면안을 비교하고 후자를 권했다. 회전 자체의 필수 여부와 방향 선택을 확인했다. | [응답](behavior-ambiguous-means.md) |
| 경험에 근거한 비전문적 피드백 | 작고 어두운 인물이라는 사용자 관찰을 시선·자세·구도·지속 시간의 수정으로 연결했다. 작법 강의를 하지 않았다. 제공되지 않은 초안을 직접 봤다고 주장하지 않았다. | [응답](behavior-experienced-feedback.md) |

갱신 전 기준 응답은 [skill-baseline.md](skill-baseline.md)에 있다. 그 응답도 두 대안과 필수 사실을 보존했다. 방향 선택이나 위임을 명시적으로 요청하지 않았지만 실제 제작을 시작하지도 않았다. 이를 무단 제작 실패로 기록하지 않는다. 갱신 후 같은 입력의 응답에는 명시적인 선택 요청이 있었다. 각 조건을 반복 측정한 대조 실험이 아니므로 향상률이나 일반적인 성공률을 계산하지 않는다.

[입력과 관찰 기준](behavior-cases.json), [검사 중 소스 해시와 호출 조건](behavior-source-receipt.json)을 함께 보존한다. 원화 생성, 실제 재생, 관객 반응과 사용자 수락은 이 검사 범위에 포함하지 않았다.

이 다섯 응답을 수집한 뒤 Task 3 독립 검토에서 후보마다 기대하는 정서·서사 효과를 가설로 적으라는 문구를 두 지침에 추가했다. 위 소스 해시는 문구 추가 전 상태다. 기존 응답·해시를 최종 소스의 새 실행 결과로 바꾸지 않았으며, 이 작은 문구 수정 뒤 다섯 사례를 반복 실행하지 않았다. 수정 문구는 Task 3 재검토 대상으로 구분한다.
