# Cinewright 작법 검토 종합

검토 대상은 1.1.0 스킬과 카운팅스타 1–3신 첫 검토본이다. 사용자는 과도하게 직접적인 감정 표현, 반복 확대, 배경 애니메이션의 부재를 지적했고 기존 작법을 스킬에 반영하는 것이 목표라고 명시했다. 이번 산출물은 검토와 변경 제안이며 스킬·영상 구현은 변경하지 않았다. 기존 r2 제작에는 중단을 요청했다.

## 판단

반복 줌은 실제 영화에 존재한다. ASC의 Zsigmond 인터뷰와 분석은 《McCabe & Mrs. Miller》의 마지막 세 줌을 구체적으로 설명한다. 이 사례는 줌의 반복을 금지할 근거가 없음을 보여 준다. 현재 검토본의 반복 확대가 적절함을 입증하지는 않는다.

현재 구현은 하나의 평면 원화에 인물과 환경을 함께 담고 크롭 크기를 바꾼다. 카메라 이동을 대신하는 2D 확대, 인물 연기, 환경의 움직임을 제작 단계에서 충분히 구분하지 않았다. 배경을 독립적으로 저작할 기존 기능과 반사광 예제가 있으므로 엔진 변경이 필요하다는 근거는 없다.

과도한 감정 표현은 사용자 피드백으로 확인됐다. 원화 선택 기록은 작은 얼굴을 가진 넓은 구도보다 얼굴과 손짓의 명시성을 우선한다. 절제된 대안을 실제 시간으로 비교했다는 근거는 없다. 기존 Hitchcock 참고에는 손·눈·사물·편집으로 과장된 얼굴 연기를 대신하는 원문의 설명이 충분히 반영되지 않았다.

기존 지침은 이미 기본 카메라 드리프트와 매 박자 교체를 경계한다. 이번 실패를 모든 지침의 부재로 판단하지 않는다. 선택한 작법을 원화 구성·움직임·편집·재생 검토로 연결하지 못한 실행상 실패와, 이를 구체화하는 작은 문서 보완 필요를 구분한다.

## 필요한 변경 범위

1. `references/craft.md`: 기존 Hitchcock 항목에 절제된 감정 전달의 근거를 보완한다. 정지 구도, 컷, 이미지 내 크롭 이동, 공간상의 카메라 이동을 각자의 기능으로 구분한다. 반복 줌과 의도한 음악 동기화를 유효한 선택으로 유지한다.
2. `references/craft-execution.md`: 환경의 움직임을 위한 자산 분리·가림·시간 저작 항목과 기존 반사광 예제 연결을 추가한다. 원화를 생성하기 전에 움직일 대상이 무엇인지 정하도록 한다. 바람·입자·깜빡임 등을 공통 기본값으로 만들지 않는다.
3. `references/stillcuts.md`: 기존 음악 프레이즈·쉼 지침과 실제 제작 판단을 연결한다. 같은 구간의 고정 구도와 확대, 상황·시선에 의한 감정과 명시적 표정의 차이를 필요한 경우 실제 짧은 출력으로 판단한다. 모든 작품에 비교안 수나 확대 횟수를 강제하지 않는다.
4. 검수: 기술 정상, 프레임에서 읽히는 인과관계, 원속도에서의 카메라·연기·음악 관계를 구분한다. 재생하지 않은 시간적 품질에는 유지 판정을 확장하지 않는다. 사용자의 실제 감상 피드백을 이번 수정 근거로 사용한다.

## 교차 확인

Left가 frozen source와 live source 일치, 영상 해시, 크롭 구간, 별도 환경 드로잉과 beat binding 부재를 확인했다. Right의 추가 확인 항목 중 이 부분은 기존 증거로 충족한다. 고양이의 시선은 하늘과 소녀 중 어느 쪽인지 모호할 수 있으나 확정된 시선축 위반은 아니다. 2.25배 반응 화면은 연속 줌이 아니라 고정 크롭 후 컷이다. 기존 독립 검토와 리드 보고는 최초 사용자 검토 가능 여부만 인정했고 직접 전속 시청·청취의 한계를 밝혔다. 이를 카메라 리듬이나 예술적 성공의 통과로 해석하지 않는다.

리드는 양쪽 보고서와 현재 구현, 기존 반사광 예제, 아래 원문을 대조했다. 작법의 근거와 적용 판단은 구분했다. 원속도 직접 시청·청취는 이번 검토에서도 수행하지 않았다.
