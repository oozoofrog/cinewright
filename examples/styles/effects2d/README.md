# Isolated Canvas effects

`node examples/styles/effects2d/build.mjs UNUSED_PROJECT` packages independent public helpers through materializeKit. `scene.mjs` uses six independently inspectable panels: complex hole+iris alpha mask, pressure curve+dabs+glaze, object hatch+paper stipple, held redraw+ledger erasure, analytic emitter+independent trail, and known sRGB/alpha patches over black/white. The 192-frame reel changes then settles; it is a diagnostic example, not a fourth aesthetic pack.

`node examples/styles/validate.mjs PROJECT STORE OUTPUT` exports both sizes and checks seek/PTS/autoplay/flash. `node examples/styles/effects2d/probes.mjs PROJECT STORE OUTPUT` checks actual pixels: evenodd/nonzero hole, translucent erasure, glaze alpha, black/white red blending and deterministic pressure/dabs. Output PNG alpha is supported internally; MP4 is opaque yuv420p. CPU negative/range checks live in style-common and line-wash tests. The particle max is2000; analyticTrail max32 independently sampled states. Browser shaders and real 3D-specific probes are in the separate expressionist-space effects reel. This page does not claim a physical pigment solver or human safety/quality acceptance.
