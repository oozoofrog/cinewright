# Music Box Dancer: owned paper / printed counterpoint

Two original Canvas2D treatments of **the same source timing**. No source-video images, performer likeness, remote assets, replacement soundtrack, or publication-clearance claim. The SVG is original procedural art. Georgia is an optional local system font, not a downloaded asset.

## Integrator usage

Run from the toolkit checkout, with a music-service project that already contains its audio assets and canonical JSON:

```js
import fs from 'node:fs/promises';
import { buildMusicBoxProject } from './examples/music-box-dancer/build.mjs';
const project = '/absolute/private/project';
const source = JSON.parse(await fs.readFile(`${project}/music/source.json`, 'utf8'));
const derived = JSON.parse(await fs.readFile(`${project}/music/derived.json`, 'utf8'));
await buildMusicBoxProject({ project, source, derived, variant: 'theatre' });
// Or variant: 'counterpoint'. Default size [1920,1080]; use [960,540] for a draft.
```

For A/B, ingest/copy the same project-local audio + canonical data into **two distinct private directories**, then build each variant. The builder neither trims nor retimes audio. It clones `source.audio` verbatim into `work.audio`; frames/fps must agree with derived. It accepts `source.frames` or `source.requiredFrames`, falling back to derived only when absent. No music synthesis fallback exists. End-preservation and AAC remux remain music/integration service responsibilities.

Only layer **scene** exists; it consumes canonical `$data` `music.*` channels (consumers must be `['scene']` or empty, which is defaulted in the work copy only). It reads each active binding using its declared coordinate space. `music.energy` can drive a small local hinge; direct `tracks.energy` is the fallback. `api.json('music/derived.json')` supplies frame onsets, energy and sections, without importing the music service. Canonical events include original seconds/quantization diagnostics; no fields or existing file bytes are rewritten. `events.onsets`, `events.beats`, `tracks.energy` are validated. Existing differing canonical JSON is an error, not overwritten analysis.

Use existing freeze/play/render commands on the resulting project. Scene, recipes, SVG, motion and effects are materialized **inside** the project: no toolkit-external browser import survives. Files are tracked by `.cinewright-kit.json` and `.music-box-generated.json`, with last-generated SHA-256s. Rebuilds replace only unchanged generated bytes and refuse unknown files, authored edits and symlink destinations. To author a generated file, edit it normally and do not rebuild over it; build into a new project directory for another generated revision. Ledger hashes distinguish generated copies from authored edits; they are not a security signature or an atomic multi-file transaction. Do not run concurrent builders on one project.

## Public exports / units

- `modules/motion.mjs`: `clamp`, `lerp`, `ease`, `progress`, `seeded`, `noise`, `eventIndex`, `eventEnvelope`, `stagger`, `pathPoint`. Time is frames; path points are logical pixels; ease/progress are clamped [0,1]. Seed/index are integers. Events are sorted by frame. Envelope is latest-event only (not additive), with `[event, event+attack+release)` support. Noise is indexed smooth scalar noise, not an accumulating RNG.
- `modules/fx/focus.mjs`: `prepare({from,to,box,center})` -> `{evaluate,draw}`. Box is pixel `[x,y,w,h]`, center normalized. A fixed-position expanding paper aperture, closed at/before from, open at/after to. `draw(g,t,state,content)` clips a caller callback; no camera drift or blur.
- `modules/fx/accent.mjs`: `prepare({events,at,radius,attack,release,color})` -> `{evaluate,draw}`. Two local ink contact strokes; pixel radius, frame durations. No full-canvas flash.
- `modules/fx/particles.mjs`: `shapePoints(polyline,count)` and `prepare({shapes,keys,scatter,seed,radius,color})`. Equal-length pixel shapes have stable tile correspondence. Explicit keys hold, form, disperse and reform. `$scatter` is a seeded destination, not simulation. Before/after keys hold endpoints. Tiles are opaque paper squares, never glow/stars.
- `scripts/materialize-kit.mjs`: `materializeKit({project,modules})`, names `motion`, `focus`, `accent`, `particles`, `artwork`; dependencies copied automatically. `writeOwnedFiles` is the builder's ownership-ledger companion.
- `build.mjs`: `buildMusicBoxProject({project,source,derived,variant='theatre',size=[1920,1080]})` -> `{project,variant,work,kit,files}`.
- `recipes.mjs`: `limitedPose`, `groupCounterpoint`, `shapeMatch`, `visualPhases`, `energyAt`.

Effects honor `t.exposed ?? t.frame`. Theatre exposes on twos; counterpoint on ones. All evaluation is stateless and seek-order independent. No random cursor, prior-frame physics, mandatory postprocessing, or continuous camera motion.

## Three executable recipe paths

All are called by `scene.mjs`, not unused library demos. Run `node --test tests/music-box-dancer.test.mjs` to execute each plus native frozen-project pixel checks with synthetic silence. Direct Node calls are also possible:

```js
import { limitedPose, groupCounterpoint, shapeMatch } from './examples/music-box-dancer/recipes.mjs';
const events = [{ frame: 24, strength: 1 }, { frame: 48, strength: .7 }];
limitedPose({ frame: 28, events, fps: 24 }); // contact -> held pose, planted foot
// each onset belongs to one voice; delayed local answers, then a true rest
groupCounterpoint({ frame: 52, events, fps: 24 });
const shape = shapeMatch({ frames: 720 });
shape.evaluate({ frame: 240 }); // key -> scattered tiles -> figure -> rosette -> key
// shape.draw(canvasContext, {frame:240}) draws the actual paper formation.
```

### 1. Limited pose / contact / hold — theatre

Intent: a pinned miniature paper mechanism, not smooth mocap. Four discrete families (rest, anticipation, contact/hold, release); the supporting foot is fixed, the free leg and arms change silhouette. An upcoming measured onset permits 120ms anticipation; contact lasts 100ms and holds through 270ms; release finishes at 500ms. Presentation-only onset thinning (minimum 550ms in theatre; 220ms in counterpoint) avoids chattering on dense analysis and leaves time for the 500ms release to complete. Actual-source draft inspection found that 220ms kept the theatre almost permanently in contact/hold; the final uses 550ms. This never edits the canonical events. Opening/coda intentionally hold. Duet/ensemble introduce delayed, smaller paper figures, not duplicates moving in unison. Mechanical detents change by onset index, not by a perpetual spin.

The paper stage uses a restrained warm/ink palette, explicit floor contact, pinned sun, accordion botanical wings and hard phrase-boundary shot changes. The aperture reveals unfolding wings. Key/figure paper formations occupy the arch rather than covering every frame.

### 2. Group counterpoint — counterpoint

Intent: printed geometric call-and-response, with a key, triangle and four-leaf pinwheel in separate spatial voices. Onset index assigns a voice; 80ms-per-voice answer offsets, bounded local translation/quarter-turn and three answer tokens form the choreography. There is no oscillator in silence. Hard-cut horizontal / diagonal / two-plus-one / bridge compositions differ from the theatre's stage/pose rules. A subtle offset print is a flat shadow, not glow. The local hinge alone responds to energy. Opening/coda hold the main glyphs.

### 3. Shape match / purposeful reveal — both

72 indexed paper tiles form an original key outline, disperse, reform a stylized figure, become a rosette, disperse and return to the key. Fixed authored full-track fractions have unequal durations and long holds; this is not a 6s loop padded to song length. Counterpoint uses a clipped aperture to reveal the formation above its principal voices; theatre uses the key/figure in the arch and a separate spatial unfolding. The key's stem also matches a graphic paper-fold corner across counterpoint cuts.

## Musical honesty / phases / rejected alternatives

No direct listening or source-video viewing was performed in this lane. Musical form is **authored/inferred**, not a claim that this recording contains these sections. Canonical contiguous section boundaries, if available, anchor visual roles. Otherwise seven authored proportional phases (opening, solo, duet, unfold, ensemble, return, coda) govern full-track variation. Return reuses the solo composition with unfolded wings; coda restores the key and held figure. Formation's independent long-form track is authored, not beat-confidence evidence.

Rejected at design time (not audience-tested failures): endless sinusoidal dancer sway, all-voices-on-every-beat, full-screen beat flashes, automatic camera drift, generic glowing particle clouds. They remove the contact/hold/readability that these recipes require. A native synthetic proof exposed a real Canvas fill-state error (the key shaft inherited paper from its hole); this was fixed with explicit ink fill and a native shaft-pixel regression. Native evidence uses canvas-element screenshots, avoiding the host HTML's default page margin.

## Validation boundary

`node --test tests/motion.test.mjs tests/fx.test.mjs tests/music-box-dancer.test.mjs`

Synthetic 30s silent transport fixtures only: all recipe states, endpoints, invalid input, ownership refusals, canonical byte preservation, channel reads, source audio descriptor identity, frozen dependency closure, 7 sampled native frames per variant and reverse/random seeks. Mutable scene/modules are removed after freezing to prove browser independence. Captures/logs stay in lane-local `.direction/test-runs` and are not committed. Sampled screenshots are technical/model visual inspection, not actual playback listening, flash certification, audience response or user acceptance. Real-source A/B/full-song rendering, end-preservation, bounded flash screening, and source-AAC packet verification belong to integration. Copyright clearance for publication is not asserted.
